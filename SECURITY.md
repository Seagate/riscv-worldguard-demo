Riscv-worldguard-demo Security Policy

We take the security of the this project seriously. If you find any security vulnerabilities in any of the source code managed via our GitHub Organisation repositories, please report it to us as described below.

Reporting Security Issues
⚠️ Please do not publicly report any security vulnerabilities via GitHub issues.

If you have concerns or questions, please email us at paul.heath@seagate.com.

To report an actual vulnerability, please use the "Seagate Responsible Vulnerability Disclosure Policy"

Reporting Format
To make your reporting meaningful and help us understand the nature and scope of the issue, please include as much information as possible.

Preferred Languages
We prefer all communications to be in English.
